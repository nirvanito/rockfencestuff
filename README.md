**File Descriptions**

Data collection stuff:
1. scraper.py: Web scraper that pulls historical year-end ATP Singles Rankings (2000-2025)
2. clean_earnings.py: standardizes raw ATP prize money files since I got them from different sources
3. prepare_data.py: Merges the cleaned ATP rankings with the prize money data, handles some issues (e.g. different name spellings) w fuzzy string matching

Modeling:
1. rank_singles_mapping.py: As the name suggests, maps singles earnings to atp rank
2. aging_curve_analysis.py: Does a bunch of stuff:
   a. Calculates delta method aging curve
   b. corrects for survivorship bias so players dropping off tour don't artificially inflate the curve
   c. tests Lognormal vs. Power-Law distributions (Vuong test) 
   d. normalizes historical data for prize money inflation.
3. earnings_dist_2025.py: snapshot of the 2025 earnings distribution (let me know if you want me to do this with the inflation-adjusted numbers since 2015 instead), with inequality (Lorenz curve)

Simulation:
1. simulation_pricing.py: Runs a 10k Monte Carlo simulation for a portfolio of players, including calibrated lognormal distributions, bust probabilities (I'll take your input on this after you take a look at the earnings distribution), aging curves, and inflation to determine purchase price required to hit a target IRR

Visualization:
1. plot_results.py: makes data visualization
2. aging_curve_best_estimate.json: Calibrated + smoothed aging curve multipliers
3. Other .png files: charts generated by python files (aging_curves, distribution_fit, earnings_dist_2025, inflation_trends)

Sequence/pipeline:
1. Get raw data by running scraper.py and clean_earnings.py to get the base rankings and earnings files
2. Merge data with python prepare_data.py to create the mapped file (filtered_top_players_earnings.xlsx)
3. Run rank_singles_mapping.py to aggregate the ranks
4. Calibrate models with aging_curve_analysis.py to compute the aging curve multipliers, fit the distributions, and calculate the prize pool inflation rate ever year
5. Generate pngs with python earnings_dist_2025.py and python plot_results.py to output the charts
6. Run simulation_pricing.py to perform the Monte Carlo simulation and output the final target pricing
